# Автоклавщик — офлайн PWA

Полноценное статическое PWA-приложение для обучения автоклавщиков производства силикатного кирпича.

## Возможности

- работает офлайн после первого открытия;
- адаптивный интерфейс для Android, iOS и desktop;
- безопасные safe-area отступы для iPhone с Dynamic Island;
- разделы по технологии, оборудованию, SCADA, смене, циклу, конденсату, безопасности и авариям;
- поиск по ключевым словам с переходом в найденный раздел;
- тёмная тема;
- установка на устройство как приложение;
- не требует backend или базы данных.

## Публикация на GitHub Pages

В настройках репозитория откройте **Settings → Pages**, выберите **Deploy from a branch**, ветку `main`, папку `/ (root)` и сохраните. Приложение будет доступно по адресу:

`https://maarkevich.github.io/avtoklavi/`

Для корректной работы PWA нужен HTTPS — GitHub Pages его предоставляет.
